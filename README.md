# Patinhas do Cerrado — Adoção de Animais

Projeto desenvolvido por **Ana Beatriz Farias Silva**, aluna do **2.º período de Análise e Desenvolvimento de Sistemas (ADS)**, para a disciplina **Linguagem de Script para Web** — **Instituto Federal do Triângulo Mineiro (IFTM)**, Campus Uberaba Parque Tecnológico.

## Tema Escolhido

**Patinhas do Cerrado — Adoção de Animais** (`cd`, `ls`, `chmod`, `pwd`, `mkdir`? Não — divulgação e adoção responsável de cães e gatos resgatados, com destaque para Pipoca, Luna e Thor, guia de porte/energia e formulário de interesse em adoção)[cite: 16].

## O que foi feito na Atividade 1

- Criação da estrutura semântica em `index.html` com `lang="pt-BR"`, `<meta charset="utf-8">`, `<meta name="viewport" content="width=device-width, initial-scale=1">`, link de salto (`Pular para o conteúdo`), cabeçalho com navegação, seções de animais em destaque, tabela comparativa de portes, formulário de adoção, barra lateral com requisitos e rodapé com endereço[cite: 16, 17].
- Estilização em `style.css` com grid layout (`2fr 1fr` no desktop e `1fr` abaixo de `700px`), tipografia, tabela formatada e foco em acessibilidade e responsividade[cite: 17].
- Validação do HTML no W3C Validator sem erros e organização dos arquivos e imagens do projeto[cite: 16].
